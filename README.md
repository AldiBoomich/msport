# msport

A single-page WordPress theme that presents the BMW M6 E63. Portfolio piece.

**Status:** rebuilt from scratch on 2026-11-24. The previous version (a scroll-driven 3D film) was removed;
the new concept will be defined from reference sites. See [docs/STATUS.md](docs/STATUS.md) and [docs/ROADMAP.md](docs/ROADMAP.md).

## Requirements
- WordPress 6.6+
- PHP 8.2+
- Advanced Custom Fields PRO 6.x

## Development
```sh
composer install
composer lint:wpcs   # PHP coding standards
```

Based on the `_s` (Underscores) starter theme, GPL-2.0-or-later.
