# Content model (ACF Pro)

Everything a visitor can read or see on the site comes from these fields, the menu or the Customizer. Templates contain no visible text except fallbacks wrapped in `esc_html__()`.

- Field groups are stored as **ACF Local JSON** in `acf-json/` (versioned with the theme). After deploy: ACF → Field Groups → Sync.
- The JSON is generated by `tools/acf/fields.mjs` (field keys are fixed: `field_msport_<name>`), imported with `wp eval-file tools/acf/sync.php`; demo content: `tools/acf/demo-content.php`.
- Field names use a section prefix (`hero_`, `rev_`, …). Never rename a field once content exists; add a new one and migrate.
- Every field has an English instruction (the "Instructions" setting) written for a non-technical editor.
- Every section has a **Show section** toggle (true/false, default on) and an **Anchor ID** (text, default given) for the menu.
- Images are returned as **ID** and printed with `wp_get_attachment_image()` and the theme's image sizes.

Output escaping: text → `esc_html()`, attributes → `esc_attr()`, URLs → `esc_url()`, WYSIWYG → `wp_kses_post()`.

## 1. Options page: `M6 Settings`
Location: Options Page `msport-settings` (menu title "M6 Settings", icon `dashicons-performance`).

| Field | Name | Type | Instructions / notes |
|---|---|---|---|
| Wordmark | `opt_wordmark` | Text | Text shown in the header instead of a logo. Default "M6 E63". |
| Header button label | `opt_header_cta_label` | Text | Default "Hear the V10". |
| Header button target | `opt_header_cta_anchor` | Text | Anchor of the section the button scrolls to. Default `sound`. |
| Menu button labels | `opt_menu_label`, `opt_menu_close_label` | Text | The phone / tablet menu button, closed and open. Defaults "Menu" / "Close". |
| Skip link | `opt_skip_label` | Text | Keyboard skip link. Default "Skip to content". |
| Menu name for screen readers | `opt_nav_label` | Text | `aria-label` of the header menu. Default "Chapters". |
| Developer name | `opt_dev_name` | Text | Footer credit. |
| Developer link | `opt_dev_url` | URL | Portfolio / Upwork profile. Also the default link of the chapter 10 button. |
| Social links | `opt_social` | Repeater → `label` (Text), `url` (URL) | Optional. |
| Footer menu name for screen readers | `opt_footer_nav_label` | Text | `aria-label` of the footer menu. Default "Footer". |
| V10 sound file | `opt_sound_file` | File (return ID, mime: m4a, mp3, ogg, webm) | ≤ 400 KB, ≤ 15 s. |
| Sound credit | `opt_sound_credit` | Text | Optional, shown next to the player. |
| Effects | `opt_effects_enabled` | True/False | Turns WebGL and scroll scenes on/off for the whole site (for testing and weak hosting). Default on. |
| 404 title / text | `opt_404_title`, `opt_404_text` | Text / Textarea | Defaults "You hit the limiter." / "This page does not exist. The car is still running on the front page." |
| 404 button | `opt_404_button` | Text | Button back to the front page (404 and empty list pages). Default "Back to the car". |
| Empty list title | `opt_empty_title` | Text | `index.php` with nothing to list (e.g. a search without results). Default "Nothing here yet". |
| Page description | `opt_meta_description` | Textarea | `<meta name="description">` on every page. Empty: the site Tagline. |

Menus (Appearance → Menus): `menu-1` (Primary) holds the anchor links, built with Custom Links like `#rev`; `footer` holds the privacy page and other plain pages.

Every visible text of the site comes from these fields, the front page fields or the menus. The `__()` strings in the templates are only fallbacks for empty fields.

## 2. Front page field groups
Location: Page Type = Front Page. The block editor is hidden on the front page (fields only).
Each chapter below is one tab inside a single group "Front page", in page order. The page is one 3D film around the car (see DESIGN.md → Motion → Chapters): **camera angles and effects live in theme JS, text and stills live here.**

### Common fields of every chapter
Every chapter group has these fields (prefix = chapter prefix), listed once here and not repeated below:

| Field | Name | Type | Notes |
|---|---|---|---|
| Show chapter | `{prefix}_show` | True/False | Default on. A hidden chapter is skipped by the camera too. |
| Anchor ID | `{prefix}_anchor` | Text | Default given per chapter. Used by the menu. |
| Still, desktop | `{prefix}_still` | Image (ID) | Render of this chapter's camera angle, 16:9, 2560 × 1440. Shown when 3D is off (reduced motion, no GPU, Save-Data, effects off). |
| Still, mobile | `{prefix}_still_mobile` | Image (ID) | Render of the portrait camera key, 9:19.5, 1200 × 2600; used on portrait screens. Optional; falls back to desktop with focal point. |
| Focal point | `{prefix}_focal` | Text | `x% y%`, used as `object-position`. Default `50% 50%`. |

Chapters 1–8 and 10 use these; Spec sheet has only Show and Anchor (it plays over the dimmed live scene and needs no still of its own).

### 1. Hero — `hero_`
| Field | Name | Type | Notes |
|---|---|---|---|

### 3D scene (global for the page) — `scene_`
| Field | Name | Type | Notes |
|---|---|---|---|
| 3D model, desktop | `scene_model` | File (ID, mime: glb) | Prepared `.glb` ≤ 4 MB. If empty, the theme's own model is used. |
| 3D model, mobile | `scene_model_mobile` | File (ID, mime: glb) | Lighter `.glb` ≤ 2 MB. Optional; falls back to desktop. |
| Environment | `scene_env` | File (ID, mime: hdr, ktx2) | Night HDRI for reflections, ≤ 1 MB. Optional; theme ships a default. **Not read yet:** the site uses the packed panorama `assets/3d/env/shanghai-bund-*` (WebP pair from `tools/3d/hdr-pack.mjs`); a single `.hdr` upload would need a different loader. |
| Paint colour | `scene_paint` | Color Picker | Base colour of the car. Default `#050608` (Black Sapphire Metallic). Live scene only (see note below). |
| Paint gloss | `scene_clearcoat_roughness` | Range 0–0.2, step 0.001 | Clear coat roughness, lower = glossier. Default 0.012 (what the stills and the video were rendered with). Live scene only. |
| Driving speed | `scene_speed` | Range 0.5–2, step 0.1 | Speed of road, wheels and street lights. Default 1. Live scene only. |
| Model credit | `scene_model_credit` | Text | "BMW M6 (E63)" by Mona x Supercars, CC BY 4.0. Shown in the footer credits. |

The three look fields drive the live 3D scene (`inc/film.php` → `msport_film_look()`). Phones and slower computers play the pre-rendered video with the default look: after changing a field, render the video again (DESIGN.md → Video version).
