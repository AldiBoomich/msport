One-page presentation of the BMW M6 E63, told as a scroll-driven 3D film around the car.

== Description ==

The front page is ten chapters played over one real-time 3D scene (Three.js). Every text, number and image comes from custom fields, so the whole page is edited in the admin.

Required plugin: Secure Custom Fields (free, wordpress.org) or ACF PRO. Field groups ship with the theme in acf-json/.

== Installation ==

1. Upload the theme and activate it.
2. Install and activate Secure Custom Fields (or ACF PRO).
3. Custom Fields → Field Groups → Sync, to load the groups from acf-json/.
4. Settings → Reading: set a static front page.
5. Appearance → Menus: build the Primary menu from Custom Links to the chapter anchors (#front, #rev, #wheels, #sound, #specs).
